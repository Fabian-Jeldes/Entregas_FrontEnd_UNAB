# M4AE2 - ABP2

## Descripción
Actividad de evaluación que incluye dos problemas de programación en JavaScript.

## Problemas

### Problema 1: Conversor de Dólares a Pesos Chilenos
- Convierte montos en dólares a pesos chilenos
- Tipo de cambio: 745 CLP por USD
- Validación de entrada para números positivos

### Problema 2: Validador de Subsidio de Arriendo
- Evalúa elegibilidad para subsidio habitacional chileno
- Requisitos: mayor de 18 años, cédula vigente, ahorro mínimo 4 UF, vulnerabilidad ≤70%
