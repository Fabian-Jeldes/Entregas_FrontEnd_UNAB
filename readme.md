# M5AE1-ABP1

Proyecto de ejemplo para el módulo de Programación Orientada a Objetos (POO) en JavaScript.

## Descripción
Este proyecto permite registrar pacientes y mostrar sus datos utilizando funciones constructoras y prototipos en JavaScript (ES5).

## Estructura
- `index.html`: Página principal con botón para mostrar pacientes.
- `assets/js/main.js`: Lógica de registro y visualización de pacientes.
- `assets/CSS/styles.css`: Estilos de la página.

## Uso
1. Abre `index.html` en tu navegador.
2. Haz clic en el botón "Mostrar Pacientes" para ver los datos registrados.
