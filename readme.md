# M4AE4-ABP5

Este proyecto contiene ejercicios prácticos de JavaScript para el módulo de Front-End.
Funcionamiento a través de un botón que despliega las imágenes de los ejercicios respectivos. 

## Ejercicios incluidos
- Sumatoria de números
- Verificación de número primo
- Cuenta regresiva
- Suma de números pares
- Tabla de multiplicar
- Ordenamiento de arreglos

## Cómo usar
1. Abre el archivo `index.html` en tu navegador web.
2. Interactúa con los ejercicios usando los botones e inputs disponibles.
3. El código fuente de los ejercicios está en `assets/js/main.js`.
