# M4AE3-ABP4

Proyecto de ejercicios interactivos para el Módulo 4 del curso Front End UNAB.

## Descripción
Este proyecto contiene una interfaz web moderna e interactiva que permite resolver 5 ejercicios de JavaScript:

1. **Crear un arreglo de largo n donde cada elemento es el doble del anterior.**
2. **Obtener el mayor número de un arreglo de números.**
3. **Obtener el día de la semana según su número (1=Lunes, 7=Domingo).**
4. **Buscar un elemento en un arreglo de números.**
5. **Ordenar un arreglo de números desordenados ascendentemente.**

## Estructura del proyecto
```
index.html         # Interfaz principal
assets/
  js/
    main.js        # Lógica de los ejercicios y conexión con la interfaz
css/
  styles.css       # Estilos personalizados
```

## Uso
1. Abre `index.html` en tu navegador.
2. Utiliza las tarjetas para interactuar con cada ejercicio:
   - Ingresa valores y haz clic en los botones para ver los resultados en pantalla.

## Requisitos
- Navegador web moderno
- Conocimientos básicos de JavaScript y HTML (opcional, para modificar o aprender del código)
