# 🌿 VerdeModa

VerdeModa es un proyecto web que promueve la moda sostenible, combinando estilo y conciencia ecológica. 
Este sitio responsive presenta un catálogo interactivo, recursos educativos y una experiencia de usuario optimizada para diversos dispositivos.

## 🧵 Características

- Catálogo de productos 
- Sección de ficha de recursos
- Formulario de contacto

## ⚙️ Tecnologías Utilizadas

- HTML
- CSS
- Metodología BEM
