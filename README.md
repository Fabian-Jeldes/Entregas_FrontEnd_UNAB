# Smart-EV - M3AE4 ABP4

Este proyecto es una maqueta web para la gestión de vehículos eléctricos, desarrollada como parte del módulo Front End Trainee. Utiliza HTML, SASS y CSS siguiendo la arquitectura 7-1 para organizar los estilos.

## Características principales
- Página principal con información sobre la plataforma Smart-EV.
- Botones interactivos con modelo de cajas (padding, borde, margen, bordes redondeados y efecto hover).
- Sección de imágenes representativas.
- Footer con enlaces a redes sociales.

## Estructura del proyecto
```
├── html/
│   └── index.html
├── css/
│   └── styles.css
├── sass/
│   ├── styles.scss
│   ├── abstracts/
│   ├── base/
│   ├── components/
│   ├── layout/
│   └── pages/
└── package.json
```

## Instalación y uso
1. Clona el repositorio. (gh repo clone Fabian-Jeldes/Entregas_FrontEnd_UNAB)
2. Compila los archivos SASS para generar el CSS.
3. Abre `html/index.html` en tu navegador para ver la maqueta.
